# Responsive Contact Form Landing Page

## 📌 Project Overview

This project is a responsive Contact Form Landing Page built using HTML and CSS. It provides a clean and modern interface for users to enter their contact information and message.

The project focuses on frontend design, responsive layout techniques, and user-friendly form presentation.

---

## 🚀 Features

- Responsive design for different screen sizes
- Modern UI with gradient backgrounds
- Clean and organized layout
- Contact form section
- Attractive typography and spacing
- Mobile-friendly design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Web Design
